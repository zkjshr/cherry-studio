# 小世界 · Goal 模式提示词（M1）

> 用法：在新的 ZCode 会话（goal 模式）中，将下方代码块整体作为目标提示词提交。
> 一个 goal 对应一个里程碑；M1 完成并验收后，换用 M2 goal（见文末占位），以此类推。

```text
## GOAL：小世界 M1 —— 场景重构（海岛+广场+建筑+小房子+新化身+三通道聊天+小地图）

### 使命
把 world/（cherry-studio enterprise 分支）从 v1"部门园区找人"场景重构为 v2"海岛展馆"场景：
一座 lowpoly 海岛，中央广场用建筑表达内容栏目，环布可进入小房子，新化身系统，
附近/全体/房内三通道聊天，小地图点击传送。出口验收：两个客户端同时进岛互见移动、
能进同一间小房子私聊且房外不可见、小地图点击可传送。

### 唯一事实来源（先读，按顺序）
1. tjad-docs/superpowers/specs/2026-10-05-little-world-v2.md   ← 设计文档（M1 范围见 §14）
2. world/shared-contract.md                                    ← 前后端契约（本 goal 需同步修订）
3. world/README.md                                             ← 现有服务契约与运行方式
4. 现有代码：world/frontend/src/（main.ts、campus.ts、net.ts、profile.ts）、world/server/src/

### M1 交付清单
A. 场景（frontend，美术可用 3dviz-pro-max 技能辅助）：
   - 海岛地形：岛体/海滩/码头/绿化/路灯/环岛路径；lowpoly 明快白天风，纯材质色无贴图
   - 中央广场：新闻大厅、公告堂、规范馆（建筑形态，占位内容，M2 接 EKP）、排行榜大屏（占位）、答题台（占位）
   - 小房子 3-4 栋：门可点击进入，室内独立空间
   - 预留：昼夜光照钩子（M3 接真实天气 API）、节日装饰挂点（M3）
B. 化身（frontend + shared）：
   - 预设配色自定义（首启档案增加外观字段）
   - 动作：挥手/鼓掌/跳舞，快捷键 1/2/3，动作状态随 players 同步
   - 表情：快捷栏点选，头顶浮大 emoji 2 秒，附近可见
   - 名牌：昵称 + 部门（等级头衔前缀结构预留，M2 填充）
C. 聊天与房间（server + frontend）：
   - chat scope 增 room；服务端按 附近8m/全体/房间 路由广播
   - 小房子进出协议（进入/离开/满员拒绝），≤6 人/间，房内消息不出房
   - 移除坐班小人逻辑：players 仅含场景内玩家；心跳数据转管理端统计（/api/heartbeat 保留）
D. 小地图（frontend）：鸟瞰小地图，点击传送
E. 契约与测试：
   - 修订 world/shared-contract.md 与 world/README.md 至与新实现一致
   - world/server npm test 全绿（改造既有 23 项 + 新增房间/房内聊天/满员用例）
   - world/frontend npm run build 成功；两客户端手动联调通过出口验收

### 约束
- 鉴权/端口/启动方式不变：world :8788、GATEWAY_TOKEN 语义、node:sqlite；不引入重型依赖
  （Three.js 版本不升级，除非必要）
- 50 人上限保留（close 4000 room_full）；代码按 500 并发预留但不实现分区
- 不做：语音、移动端、NPC、客户端本地通知、EKP/题库/积分（M2）
- git 提交遵循仓库现有钩子流程（prek；提交前停 dev 实例）

### 验收（全部满足才算完成）
1. npm test 全绿；npm run smoke 通过
2. 前端构建成功，页面可进岛：出生在广场/码头，WASD+点击寻路+Shift 跑均可
3. 双实例联调：互见移动与动作；附近聊天 8m 生效；全体聊天所有人可见
4. 两端进同一小房子：房内互见消息，房外第三方看不到；第 7 人进房被拒
5. 小地图点击传送生效；点建筑弹对应占位面板
6. shared-contract.md / README.md 与实现一致（无"文档说 A 代码做 B"）
```

## 后续 goal（占位，M1 验收后逐个细化）

- **M2 goal**：EKP 拉取（脚本落库位置 PULL）+ 公告建筑内容、每日一题+积分+等级头衔+排行榜、UGC 出题+审核、百事通后台"小世界"页签（网关代理 `/admin/api/world/*`）、可配置项清单落地。

### 北极星（全程校准）
每周进过场景的用户中 ≥30% 当周有互动（答题/聊天/出题）；辅助：场景 DAU、答题参与率、UGC 出题数、停留时长。
