# 小世界（Little World）设计文档 v2 —— 3D 海岛展馆 + 游戏化知识平台

- 日期：2026-10-05；状态：**设计已确认（五轮访谈逐条拍板），进入实施**
- 取代：`2026-10-05-little-world.md`（v1，园区找人定位，见 §13 差异对照）
- 仓库：cherry-studio（enterprise 分支）；代码：`world/`（server + frontend）+ 客户端集成
- 访谈方法：苏格拉底式设计访谈（2026-10-05，五轮，逐块覆盖定位/场景/内容/交互/后台/数据）

## 1. 一句话定位

小世界 = **原有业务系统的新型交互入口**：一座 3D 海岛展馆，把院里的新闻公告、项目作品、知识规范搬进场景，用每日答题、排行榜、轻社交等游戏化方式，让全院员工"以玩的形式提高技能"、活化原有平台的内容。

> 给院领导的一句话：一个让 3000 人愿意自己打开的、会讲故事的企业门户。

## 2. 规模与在线语义

| 项 | 决策 |
|---|---|
| 潜在用户 | 全院 3000 人；对 AI 感兴趣约 700 人为核心盘 |
| 一期目标 | 同在线 50 人；200 即成功；架构上限 500 |
| **在线语义（修订 D8）** | **在线 = 打开场景页面的人数**（场景内活跃 WS 会话）；心跳保留仅作管理端统计（"装了客户端的人数"），不再驱动场景内表现 |
| 坐班小人 | **作废**（v1 的 scene=false 坐姿化身不再渲染） |
| 成功画面 | 广场门庭若市：看公告、卷答题、发求助、互相闲聊 |

## 3. 场景设计（海岛）

- **整体**：一座 lowpoly 海岛——中央广场（热闹公共区）+ 环布可进入小房子 + 海滩/码头/绿化/路灯；明快白天 lowpoly 风格，纯顶点色/材质色，无贴图依赖。
- **广场建筑**：栏目用**建筑**表达而非牌子——新闻大厅、公告堂、规范馆等，**分类依据 EKP 系统的类别**（新闻/公告/规范…）；另有排行榜大屏、答题台。
- **小房子（私聊空间）**：点击门进入，≤6 人/间，房内消息只在房内广播、房外完全无感知；自由进出无门槛；一期就上。
- **昼夜与天气**：**与现实同步**——外部天气 API（天津）获取当前时间天气数据；夜间亮灯；节日装饰（圣诞树/春节灯笼等）按可配置节日日历。
- 美术基调：lowpoly 明快白天、flat-shading；昼夜系统带动灯光变化。

## 4. 化身与在场

| 项 | 决策 |
|---|---|
| 外观 | lowpoly 小人；**预设配色自由选**（首启时选择） |
| 动作 | 挥手/鼓掌/跳舞（快捷键 1/2/3）；一期三个起步 |
| 表情 | 聊天框旁快捷栏点选，头顶浮大 emoji 2 秒，附近所有人可见 |
| 名牌 | 昵称 + 部门 + **等级头衔前缀** |
| 等级 | 累计积分 → 等级 → 头衔（LV1 见习 … LV9 院士）；**纯荣誉，只给头衔不给特权**，一期就加 |
| 隐身 | 客户端设置"在小世界隐身"：只读在场（自己化身不渲染给别人，可看公告/答题） |

## 5. 交互与聊天

- 移动：WASD/方向键 + **点击寻路**都做；Shift 跑步；简单圆柱碰撞。
- **小地图**：点击传送，免跑图。
- 点建筑 = 弹对应面板（新闻大厅弹新闻列表、小房子弹进入确认、答题台弹今日题）。
- 聊天三通道：**附近（8m）/ 全体 / 房内**；屏蔽、撤回后置（内测期都是同事）。

## 6. 内容与游戏化

### 6.1 公告（EKP 管线）

- 数据来源：EKP 系统。**用户已有现成采集脚本**：脚本定期采集到**数据库或在线文档**，world 服务**去指定位置读**（拉取式，PULL；具体位置与格式在实施时与脚本对齐）。
- world 定时拉取 → 去重入库 → 缓存图片到本地 → 场景内按字段解析、重构展示。
- 点击公告 → **URL 直达外部浏览器**看原文；拉取失败显示上次缓存 + 数据时间角标。

### 6.2 每日一题

- 题库：脚本从网上采集 + **UGC 互相出题**；按用户**部门** + **答题时自选方向**匹配题库（类 B 站硬核会员答题，量少；方向是临时选择，不是档案字段）。
- 规则：答对 +10 分；多选题选不全 +5 分；答错不扣分；**不防作弊**（去翻知识库也算学习）。
- UGC 出题：答题台"我要出题"表单（题干+选项+答案+分类）→ **管理员审核上架** → 被采用 +20 分。
- 答题交互：HUD 随时可答；答题台是"仪式感入口"（走近弹出今日题，完成有撒花等反馈）。

### 6.3 积分与排行榜

- 排行榜：**总榜 / 周榜 / 部门榜**，周榜每周清零重赛（大屏展示）。
- 积分一期纯荣誉；未来 token 化 + **AI 专班**不定期活动兑换实物。
- 活动配合：一期 = 广场聚人 + **系统公告弹窗**宣发专班活动（管理后台发送，场景内顶部横幅+可关闭居中弹窗，30 秒自动收起，同一公告只弹一次）；活动专区（舞台/讲座）二期。

## 7. 系统 UI（"像手游一样"，分期）

- **一期 HUD**：顶部状态栏（当前在线数 / 我的积分 / 今日一题完成态）+ 底部快捷栏（聊天/表情/动作/答题/公告/小地图入口）+ 引导浮层。
- **二期**（随小游戏一起）：背包、兑换商店、任务日历。
- HUD 完整布局与二期演进在设计实施时出视觉稿。

## 8. 新手引导

任务清单式（右上角 4 个小任务）：逛到公告大厅 → 去答题台 → 进一次小房子 → 发一个表情；每步 +5 分，全部完成 +20；**可跳过不强制**；也允许自由探索。

## 9. 管理后台（与百事通统一）

- **形态**：百事通（网关）后台加"小世界"页签，网关代理转发 `/admin/api/world/*` → world 服务；单一入口、单一 token、一套视觉；world 不做独立后台 UI。
- **六件套**：题库 CRUD、UGC 出题审核队列、系统公告发送、排行榜查看+周榜手动重置、EKP 同步状态监控、用户列表（昵称/部门/最近在线）。
- **可配置项清单**（进后台配置存储，实施时按此落地，用户终审）：答题开放时段、积分规则（各行为分值）、周榜重置日、节日日历、天气 API 配置、隐身默认值、小房子数量/容量、昵称敏感词、轮询间隔、在线判定窗口。
- **使用数据是百事通平台级需求**：埋点/使用统计体系对齐平台，后台能看全平台用户使用数据，小世界事件是其中一类。

## 10. 客户端集成（沿用 + 增量）

- 沿用：侧栏「小世界」入口（市场下方）、设置开关、world_url 配置链、webview、主进程心跳（降级为管理端统计用）。
- 增量：设置页加"在小世界隐身"开关，隐身参数传给 webview。
- 一期不做客户端本地通知（webview 未开收不到场景消息，可接受）；关闭客户端即场景掉线。

## 11. 数据与指标

- **北极星**：每周进过场景的用户中 **≥30% 当周完成过至少一次互动**（答题/聊天/出题）。
- 辅助指标：场景 DAU、答题参与率、UGC 出题数、平均停留时长。
- 埋点：world 服务记事件表（进场景/答题/聊天/出题/表情…），管理后台出周报；体系对齐百事通平台级使用数据需求。

## 12. 服务契约增量（相对现有 world/server）

| 域 | 变更 |
|---|---|
| WS 聊天 | scope 增 `room`（房内）；服务端按 附近/全体/房间 路由广播 |
| WS 房间 | 新增小房子进出消息（进入/离开房子；容量 6 上限校验） |
| players | 仅 scene 内玩家（去掉 scene:false 坐班条目）；心跳数据转管理端统计 |
| 档案 | profile 增外观（配色）；积分/等级字段 |
| 新增存储 | 题库、答题记录、积分流水、排行榜、UGC 出题+审核态、系统公告、事件表、配置表 |
| 新增定时 | EKP 数据拉取（从脚本指定位置读）、周榜重置、天气同步 |
| 新增 REST | 答题（取题/提交）、排行榜、系统公告、配置、事件上报 |
| 新增 Admin API | `/admin/api/world/*` 六件套，供网关代理 |
| 超员 | 保留 50 上限（close 4000），架构按 500 预留 |
