# 账号设置

在账号中心点击 账号设置 ，即可管理您的个人信息和登录密码。

## 个人信息
账号的基础信息以只读方式显示，包括：
| 字段 |
| 说明 |
| 您注册时使用的用户名。 |
| 与账号关联的邮箱地址。 |
如需修改用户名或邮箱，请联系组织管理员或通过工单提交申请。

## 修改密码
按以下步骤修改登录密码：
- 在 当前密码 输入框中输入旧密码，验证身份。
- 在 新密码 输入框中设置新密码（至少 6 个字符）。
- 在 确认新密码 输入框中再次输入相同的新密码。
- 点击 保存 。
修改成功后，下次登录请使用新密码。
为保障账号安全，建议定期更换密码，并避免与其他平台使用相同密码。
