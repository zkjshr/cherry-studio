# 维护与调优


## 修改配置
在知识库列表点击 设置 ，可以修改名称、描述以及重排模型策略。
何时修改分块大小？ 掐头去尾 分块大小 可能过小；如果 AI 回复包含了大量无关的废话，说明 分块大小 可能过大。修改此参数通常需要重新上传/处理文档。

## 验证检索效果
为了确保知识库配置正确，请按以下步骤验证：
- 前往 助手管理 ，创建一个测试助手。
- 在 知识库设置 中关联刚刚创建的知识库。
- 成功标志： 助手不仅回答正确，而且鼠标悬停在回答上时，能看到 引用来源 指向您上传的文档。
