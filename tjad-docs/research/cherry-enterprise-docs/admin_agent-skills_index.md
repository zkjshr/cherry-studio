# 

入口路径： 侧边栏 → 资源库 → 智能体技能（第一个 Tab）
前置依赖： 智能体技能在客户端本地执行脚本，需要预装运行时： Python 、 Node.js ，Windows 用户还需安装 Git for Windows（含 Git Bash） 。未安装时技能调用会启动失败。下载链接见 /zh/docs/client#%E8%BF%90%E8%A1%8C%E6%97%B6%E4%BE%9D%E8%B5%96 客户端 → 运行时依赖 。

## 技能列表
技能列表展示所有已添加的智能体技能，包含以下信息：
| 字段 |
| 说明 |
| 技能的标识名称。 |
| 技能所属的分组，决定哪些用户组可以使用该技能。 |
| 技能的功能说明。 |
| 下载 （导出技能配置文件）和 删除 （从列表中移除技能）。 |
支持通过搜索框按名称快速查找技能。

## 添加技能
点击列表右上角的 添加 按钮，系统提供两种添加方式：

### 手动添加
适用于企业自建技能或第三方自定义技能。
操作步骤：
- 输入技能 名称 （必填）。
- 输入技能 描述 （可选），简要说明技能用途。
- 上传技能 文件 （支持 .md 或 .zip 格式），可拖拽文件到上传区域或点击选择。
- 点击 创建 完成添加。

### 从市场下载
打开技能市场浏览器，从社区技能市场中浏览并下载预置技能。
操作步骤：
- 在搜索框中输入关键词查找所需技能。
- 可通过排序方式（如按星标数）筛选热门技能。
- 浏览技能卡片，查看名称、来源、描述和星标数。
- 点击技能卡片右下角的 下载 按钮，即可将技能添加到资源库。
技能市场的资源由社区收集整理，托管在 GitHub 上，部分地区可能无法正常下载。
使用流程： 技能
