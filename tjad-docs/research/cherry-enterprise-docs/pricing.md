# 定价方案


## 订阅套餐
Cherry Studio 企业版采用 订阅制 ，根据团队规模选择套餐：
支持的支付方式：
- 支付宝 — 扫码即时到账
- 对公转账 — 适合需要开票的企业

## Token 消耗
AI 对话按 Token 消耗计费。不同模型的 Token 单价不同：
- Token 余额可随时充值
- 在管理后台查看组织和成员级别的用量统计
