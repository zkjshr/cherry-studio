# 调用日志


## 日志详情
点击列表右侧的 查看 (眼睛图标) ，将弹出详细信息卡片：
- 用户： 发起调用的用户名称。
- 时间： 调用发起时间（精确到秒）。
- 模型： 使用的模型 ID（如 agent/deepseek-v4 ）。
- 提供商： 对应的服务商渠道（如 Express ）。
- Token 使用统计： 输入 Token: 本次请求的输入消耗量。 输出 Token: 本次请求的输出消耗量。 总计 Token: 输入与输出的合计值。

## 应用场景
- 故障排查： 回复截断 报错
- 合规审计： 确认特定时间段内的调用是否符合企业规范。
