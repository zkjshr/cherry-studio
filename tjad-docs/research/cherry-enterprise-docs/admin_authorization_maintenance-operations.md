# 维护操作

入口路径： 管理后台 → 授权管理 → 页面底部的 刷新信息 / 授权管理 按钮

## 刷新授权信息
当您完成了续费或扩容（例如购买了更多的用户数）后，本地系统可能不会立即同步。
- 点击底部的 刷新信息 按钮。
- 系统将强制向授权服务器请求最新的 License 状态。
- 成功标志： 过期时间 用户限制

## 撤销 License (迁移授权)
如果您需要更换服务器硬件，或者将生产环境迁移到新的私有云环境，您需要先释放当前的授权，才能在由于新机器上激活。
- 点击 刷新信息 按钮旁边的 ┇ (更多选项) 图标。
- 在弹出的菜单中选择 撤销 License 。
- 在确认弹窗中输入确认信息（如要求）。
撤销 License 会立即解除当前服务器的授权绑定！
- 所有非管理员用户可能无法登录。

## 常见问题 (FAQ)
Q: 为什么刷新信息失败？
用户限制
A: 您有两个选择：
- 前往 用户管理 ，删除或禁用不再使用的离职员工账号，释放名额。
- 联系 Cherry Studio 销售代表购买额外的用户配额（User Seat）。
Q: License 过期后数据会丢失吗？
A: 不会。 授权过期仅限制服务的访问（如无法对话、无法登录），您的知识库、模型配置和历史对话数据依然保留在数据库中。一旦导入新的有效 License，系统即刻恢复正常。
