# 网络设置


## 配置步骤
- 导航至 系统设置 > 网络设置 。
- 确保企业代理服务器/网关已正常运行（如内网需经统一出口访问外部 API 的场景）。
- 在下方输入框中填入代理地址。

## 配置项说明
| 参数 |
| 描述 |
| 示例值 |
| 全局 HTTP/HTTPS 代理地址。Cherry Studio 的核心对话、模型列表更新均通过此通道。 |
| (可选) 专为 Cherry Studio 内置小程序或插件服务的代理地址。通常与系统代理保持一致。 |

## 代理端口参考
本地监听端口 http://<地址>:<端口> 。
注意 ：
- 请勿填写 socks5:// 协议，Cherry Studio 目前主要支持 http:// 协议代理。
- 配置完成后，建议去 模型管理 页面点击 Check 按钮验证连通性。
