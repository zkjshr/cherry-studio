# 更新日志

入口路径： 管理后台 → 关于我们 → 更新日志

## 日志结构说明
系统按时间倒序排列所有历史版本，每个版本卡片包含以下信息：
- 版本号： 如 v0.4.10 。
- 发布日期： 如 2026/03/30 。
- 变更详情： 具体的功能点描述。

## 变更类型图例
为了方便快速查阅，更新条目使用了不同颜色的标签进行分类：
| 标签类型 |
| 颜色 |
| 含义 |
| 示例 |
| strong 新功能 (New Feature) |
| 绿色 |
| 不仅限于优化，而是新增了系统能力。 |
| strong 修复 (Fix) |
| 橙色 |
| 针对已知 Bug 或故障的修正。 |
| strong 改进 (Improvement) |
| 蓝色 |
| 性能优化、UI 调整或体验升级。 |
最佳实践： 在遇到系统异常（如数据统计不准、页面显示错位）时，建议先查看最近一次更新日志的 修复 类目，确认是否为已知问题并已在最新版中修复。
