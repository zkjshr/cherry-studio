# 概览界面


## 核心功能区 a #heading8ca0746f50e147119c6c47d6dded5dd2-he-xin-gong-neng-qu-0 heading8ca0746f50e147119c6c47d6dded5dd2-he-xin-gong-neng-qu-0
位于页面顶部的工具栏提供高效的查找功能：
- 搜索用户 ：支持输入 用户名 进行模糊匹配，快速定位特定员工。
- 全部状态 ： 活跃 ：正常使用的账号。 未激活 ：已被禁用或尚未完成初始化的账号。
- 全部分组 默认分组 开发组
数据表格直观展示了用户的关键身份信息：
| 字段名称 |
| 说明 |
| 用户的系统登录名及显示名称。 |
| 用户的唯一通讯标识，用于接收通知及找回密码。 |
| 显示特殊权限标识（如 strong 管理员 ），普通用户此栏为空。 |
| 用户当前绑定的权限组，决定了其可访问的模型资源。 |
| strong 活跃 （绿色标签）或 strong 未激活 （灰色标签）。 |
| 账号初始注册的时间戳。 |
| 包含编辑、密钥管理、删除等高频操作入口。 |
