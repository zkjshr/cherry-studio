# 趋势与分布可视化


## 使用趋势
通过折线图展示 Token 消耗的时间序列变化。
- 蓝色曲线： 总 Token 消耗。
- 绿色曲线： 某具体维度的参照（通常为输出 Token）。
- 价值： 识别业务高峰期（Peak Time），辅助管理员合理规划并发配额。

## 按模型分布
条形图展示了消耗量最大的 Top 模型。
- 交互： 悬停在条形图上可查看具体数值。
- 价值： 了解员工偏好。例如，如果 qwen3-max 消耗极高，可考虑引导员工在非关键任务中使用更经济的 qwen3.5-flash 或 deepseek-v4-flash 。
