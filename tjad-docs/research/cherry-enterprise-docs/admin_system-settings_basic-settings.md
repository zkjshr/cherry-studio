# 基础设置


## 配置说明
- 进入 系统设置 > 基础设置 。
- 根据实际需求调整同步参数。

## 参数详解
| 参数项 |
| 描述 |
| 推荐值/操作 |
| 设置管理后台中金额相关数据的显示货币单位。 |
| 可选 strong USD （美元）或 strong CNY （人民币）。根据企业结算币种选择。 |
| 控制客户端本地数据（如对话记录、设置）自动同步到云端/服务器的频率。单位为分钟。 |
| strong 默认值：1 br • strong 低频 (5-10) ：适合低配设备，减少后台资源占用。 br • strong 高频 (1) ：最大限度防止突发断电导致的数据丢失。 |
提示 ：修改此设置后，应用会自动保存更改。如果您在网络环境较差的情况下使用，建议适当延长同步间隔。
