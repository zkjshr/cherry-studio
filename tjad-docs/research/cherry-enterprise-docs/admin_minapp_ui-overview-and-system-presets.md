# 界面概览与系统预设


## 界面组成
列表分为两类应用：
- 系统预设 (System): Cherry Studio 官方精选的主流 AI 服务（如 DeepSeek、通义千问、智谱 GLM 等）。此类应用由官方维护地址，管理员仅需控制开启/关闭。
- 自定义 (Custom): 由企业管理员手动添加的内部或第三方链接。
为什么有些应用无法删除？ 系统预设的小程序是硬编码在系统中的，为了保证服务的稳定性，仅支持 禁用 （隐藏），不支持物理删除。

## 快速启用/禁用
在列表右侧的 已启用 列，通过开关即可控制该应用是否显示在员工的客户端侧边栏。
- ON (开启): 所有企业成员重启客户端后，均可在侧边栏看到该图标。
- OFF (关闭): 该应用将被隐藏，但配置保留。
