# 创建与配置智能体

入口路径： 管理后台 → 智能体管理 → 点击右上角 新建智能体 按钮

## 快速设置
最简化的创建流程，仅需填写头像、名称和主模型即可完成创建。
| 参数 |
| 说明 |
| 智能体的表情符号标识，点击可更换。 |
| 智能体的唯一标识名称。 |
| 智能体使用的主要 AI 模型，从已配置的服务商模型列表中选择。 |

## 基础设置
配置智能体的描述文案和系统指令（System Prompt）。
| 参数 |
| 说明 |
| 同快速设置。 |
| 同快速设置。 |
| 简要描述智能体的职能和用途，方便用户理解。 |
| 定义智能体的行为规则和角色设定，作为系统提示词注入每次对话。 |
| 开关控制。开启后用户可查看系统指令内容，关闭则对用户隐藏。默认开启。 |

## 模型设置
配置智能体在不同任务阶段使用的 AI 模型。三模型架构允许在性能和成本之间取得最佳平衡。
| 参数 |
| 必填 |
| 说明 |
| 是 |
| 用于生成响应的主要模型。建议选择能力最强的模型（如 DeepSeek-V4、Qwen3-Coder-Plus 等）。 |
| 否 |
| 用于复杂规划和推理任务的模型。留空时使用主模型。建议选择推理能力强的模型。 |
| 否 |
| 用于简单任务的小型快速模型。留空时使用主模型。适合选择响应速度快、成本低的模型。 |
模型选择建议： 主模型选择 DeepSeek-V4 或 Qwen3-Coder-Plus 级别；规划模型可与主模型相同或使用 GLM-5.2 等推理强模型；快速模型建议使用 Qwen3.5-Flash、DeepSeek-V4-Flash 等轻量模型以降低成本。

## 权限设置
控制智能体的运行权限，确保符合企业安全策略。
| 参数 |
| 说明 |
| 智能体启动时的初始权限模式。用户可在运行时切换（但不超过最高权限）。选项包括：普通模式、计划模式、接受编辑模式、绕过权限模式。 |
安全提示： 绕过权限

## 技能
选择智能体可使用的技能。技能来自 资源库 智能体技能
每个技能通过开关控制启用/禁用。如列表为空，请先前往 资源库 → 智能体技能 添加技能。

## MCP 服务器
选择智能体可调用的 MCP 服务器。MCP 服务器提供外部工具和数据源接入能力。
列表展示所有已配置的 MCP 服务器，每个通过开关控制启用/禁用。

## 高级设置
配置智能体的运行时行为参数。
| 参数 |
| 说明 |
| 单次会话允许的最大轮次（即 API 调用次数）。默认 100。防止智能体陷入无限循环，同时控制单次任务的 API 成本。 |
