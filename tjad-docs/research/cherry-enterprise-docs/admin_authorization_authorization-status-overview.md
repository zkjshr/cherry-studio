# 授权状态概览


## 未授权
- 试用期 ：系统处于试用阶段，可体验全部功能。试用期结束后，请导入有效的 License 文件以继续使用。

## 授权已过期
- 试用已过期 ：试用期已结束，系统功能受限。请导入有效的 License 文件以恢复完整功能。

## 授权失败
- License 校验未通过 ：授权文件签名无效、已过期或与当前部署环境不匹配。

## 授权成功
- 系统已授权 (License 有效) ：表示当前的 License 文件签名正确且在有效期内。
- 运行状态 ：右侧的 ● 正常运行 指示器表明系统已成功连接到验证服务器（或离线校验通过），未发现篡改风险。
提示： 建议管理员每月检查一次此状态。如果状态变为红色，系统可能会限制新建用户或暂停部分高级模型服务。
