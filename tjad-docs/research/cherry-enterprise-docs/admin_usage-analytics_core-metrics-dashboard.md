# 核心指标看板


## 看板概览
核心指标看板以卡片形式展示关键 KPI，提供 Token 和 金额 两种视图。

### 指标详解
| 指标 |
| 说明 |
| 在选定时间范围内成功发起到模型服务商的 API 调用次数。 |
| 消耗的 Token 总和（输入 + 输出）。 |
| 发送给 AI 的提示词（Prompt）与上下文长度。 |
| AI 生成的回复内容长度。 |
| 在选定时间内实际产生过调用的用户去重数。 |
| 被调用过的 AI 模型种类数量。 |
| 命中缓存而无需重新计算的 Token 数量，可降低实际消耗。 |
| 写入缓存供后续复用的 Token 数量。 |

### 指标详解
| 指标 |
| 说明 |
| 当前许可证的总金额额度。 |
| 已消耗的许可证金额。 |
| 许可证尚未使用的剩余金额。 |
| 许可证允许的总请求次数上限。 |
| 在选定时间范围内实际发起的 API 调用次数。 |
| 在选定时间范围内产生的实际费用。 |
| 在选定时间内实际产生过调用的用户去重数。 |
| 被调用过的 AI 模型种类数量。 |
