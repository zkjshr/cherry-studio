# 创建与编辑分组


## 前置条件
- 您必须拥有 Cherry Studio 企业后台的 管理员 权限。
- 已在 模型管理 中配置好企业可用的模型资源（API Key 及 Base URL 验证通过）。

## 创建新分组
- 登录 Cherry Studio 企业管理后台。
- 导航至 分组管理 。
- 点击页面右上角的 + 添加分组 按钮。
- 在弹出的配置窗口中，填写以下基础信息：
| 参数名称 |
| 必填 |
| 说明 |
| 示例值 |
| 是 |
| 否 |
| 用于备注该分组的职能范围或特定的资源限制策略。 |
- 完成资源配置（详见下一章节）后，点击 保存 。
验证成功： 成员数 0 。

## 编辑与管理
当业务需求变更（例如：需要为某部门临时增加模型权限）时，您可以随时编辑分组。
- 在分组列表中找到目标分组。
- 点击右侧的 设置 按钮。
- 修改相应配置后点击 保存 。
具体配置方法请参见 /[lang]/docs/admin/group-management/resource-permissions-configuration 资源权限配置 。
生效机制： 分组配置的修改（如增加模型权限）通常会 实时生效 。用户只需刷新客户端或重新登录，即可看到变更后的资源列表。

## 删除分组
在点击 删除 按钮前，请务必检查该分组下的 成员数 是否为 0。
- 若分组内仍有用户： 默认分组
- 建议操作： 请先前往 用户管理 模块，将该组用户迁移至其他分组后，再执行删除操作。
