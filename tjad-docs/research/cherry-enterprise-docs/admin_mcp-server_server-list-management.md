# 服务器列表管理

入口路径： 管理后台 → 资源库 → MCP 服务器

## 界面核心字段
| 字段 |
| 说明 |
| 服务器的显示名称（如 code mcp-server-chart ）。 |
| 服务器所属的分组，决定哪些用户组可以使用该服务器。 |
| 系统内部调用的唯一标识符（如 code antv-chart ）。 |
| 通信协议类型，如 code stdio （标准输入输出）。 |
| 服务器的功能说明。 |
| strong [关键指标] 显示当前有多少个助手正在使用该服务器。 |
| 支持 strong 查看 详情、 strong 编辑 配置或 strong 删除 服务器。 |
删除风险提示 ：在点击删除前，请务必检查 关联助手 的数量是否为 0 。如果删除了正在被助手使用的服务器，这些助手在调用工具时将直接报错。
