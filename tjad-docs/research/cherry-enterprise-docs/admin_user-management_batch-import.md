# 批量导入用户

Express 版用户可以通过 邀请链接 快速添加成员。详见 /[lang]/docs/admin/user-management/invite-members 成员邀请 。
入口： 用户管理页面右上角 导入 按钮。

## 操作流程
导入过程分为 3 个步骤：

### 步骤 1：上传文件
- 点击 下载 Excel 模板 或 下载 CSV 模板 获取标准模板文件。
- 按模板格式填写用户数据。
- 将填写好的文件拖拽到上传区域，或点击选择文件。
- 点击 下一步 进入数据预览。
| 字段名 |
| 必填 |
| 说明 |
| 用户的唯一标识，系统内不可重复。 |
| 用户初始密码。 |
| 否 |
| 邮箱地址。 |
| 否 |
| 手机号码。 |
| 否 |
| 显示昵称。 |
| 所属分组名称。若分组不存在，系统将自动创建。 |
| 否 |
| 分组描述。仅在分组不存在需要自动创建时使用。 |
| 否 |
| 是否为组管理员。可填 code true / code false 或 code 是 / code 否 ，默认 code false 。 |

### 步骤 2：数据预览
系统解析文件后展示预览表格，可在此检查数据是否正确。如有格式错误或缺失必填项，系统会高亮提示。

### 步骤 3：执行导入
确认无误后点击执行，系统批量创建用户和分组。导入完成后展示结果摘要（成功数、跳过数、失败数）。
- 模板第一行为表头，请勿修改。
- 若用户名已存在，可选择跳过或更新该用户信息。
- 分组不存在时会自动创建（仅管理员有此权限）。
- 建议首次导入前先用少量数据测试，确认格式无误后再批量操作。
