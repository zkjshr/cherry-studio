# 话题命名模型

定义 帮我写一份关于周五会议的纪要... 周五会议纪要
⚠️ 成本与性能警示 请 避免 在此处配置 推理模型 (Reasoning Models) （如 DeepSeek-V4 、 GLM-5.2 等深度思考模型）。
- 原因 杀鸡用牛刀 极度缓慢 ，还会产生昂贵的、不必要的 Token 费用。
- 最佳实践 ： 推荐模型 ： Qwen3.5-Flash 、 DeepSeek-V4-Flash 、 GLM-4.7-Flash 。 核心需求 ： 速度快、指令跟随性好、便宜 请总结为标题
