# 介绍


## 产品概览
Cherry Studio 企业版是一套面向企业的 AI 工作空间，云端托管、无需部署，注册即可开始使用：
- 零部署 ：开通账号后立即上手，无需准备服务器、无需配置基础设施
- 按需订阅 ：根据团队规模选择套餐，支持支付宝和对公转账
- 开箱即用的模型 ：内置 DeepSeek、智谱 GLM、Kimi、MiniMax、千问Qwen 等主流大模型，员工无需各自配置
准备好了吗？前往 /[lang]/docs/quickstart 快速开始 ，5 分钟完成注册并邀请团队。

## 核心优势

## 数据安全与隔离
Cherry Studio 企业版为您的数据安全提供多层保障：
| 安全能力 |
| 说明 |
| 基于分组的严格数据隔离，各组织数据完全独立，互不可见 |
| 全链路 HTTPS 加密 |
| JWT + OAuth2 认证，密码加密存储 |
| 基于角色的细粒度权限体系（管理员 / 组管理员 / 成员） |
| 独立 API Key，按用户隔离调用权限 |
企业版采用共享基础设施 + 应用层隔离架构。每个组织的数据（模型配置、知识库、助手、文件等）通过严格的分组隔离机制互相隔离，任何 API 请求都会经过身份验证和权限校验，确保只能访问本组织的数据。
