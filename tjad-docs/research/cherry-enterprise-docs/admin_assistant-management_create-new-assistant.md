# 创建新助手

点击右上角的 + 添加助手 生命

## 基础配置参数
| 参数 |
| 说明 |
| 示例 |
| 助手的视觉标识，建议根据职能选择，便于快速识别。 |
| 💻 (代码助手), ⚖️ (法务助手) |
| 助手的唯一标识名。建议采用 code [部门/职能] + 角色 的命名规范。 |
| 配置助手的系统提示词和对话提示词。定义其任务目标、输出格式及行为约束。 |
| 控制用户是否可以查看此助手的系统提示词。默认开启。 |
| 开启 / 关闭 |
注意： 详细设置
