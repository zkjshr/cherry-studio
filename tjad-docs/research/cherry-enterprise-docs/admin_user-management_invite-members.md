# 成员邀请


## 功能说明
成员邀请允许管理员生成专属邀请链接，团队成员点击链接后自行注册并加入组织，无需管理员逐一手动创建账号。
适用于：
- 团队快速扩容
- 新员工自助入职
- 跨部门协作人员加入

## 生成邀请链接

### 操作步骤
- 进入管理后台 → 用户管理
- 点击「邀请成员」按钮
- 配置邀请选项（见下方参数说明）
- 复制生成的邀请链接

### 邀请配置参数
| 参数 |
| 说明 |
| 被邀请人加入后所属的分组，决定其可访问的模型和助手资源 |
| 邀请链接的有效时间（如 7 天、30 天或永不过期） |
| 邀请链接的最大使用次数（如不限制、10 次、50 次） |

## 管理邀请链接
邀请链接在分组设置中进行管理。您可以为每个分组创建独立的邀请链接，并控制有效期和使用次数。
详见 /[lang]/docs/admin/group-management/invite-links 邀请链接管理 。

## 被邀请人注册流程
被邀请人收到链接后：
- 点击邀请链接，进入「加入组织」页面
- 页面自动显示邀请码和即将加入的分组信息
- 确认信息无误后，点击「立即加入」完成加入
- 下载客户端并登录即可使用
被邀请人需先注册账号并登录后，才能通过邀请链接加入组织。客户端登录方法详见 /[lang]/docs/client 客户端 。

## 注意事项
- 邀请链接应妥善保管，避免发送给非目标人员
- 建议为邀请链接设置合理的有效期和使用次数限制
- 被邀请人注册后，管理员仍可在用户管理中编辑其分组和权限
