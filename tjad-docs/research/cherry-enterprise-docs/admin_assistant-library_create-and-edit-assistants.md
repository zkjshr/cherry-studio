# 创建与编辑助手


## 创建助手
进入 资源库 → 助手模版 ，点击右上角 操作 → 新建助手模板 ，即可打开创建窗口：

## 编辑助手
在助手列表中找到目标助手，点击 编辑 按钮即可打开编辑窗口：

## 配置参数表
在点击 + 新建助手模板 或 编辑 后，系统将弹出配置窗口。请参考下表填写：
| 参数模块 |
| 说明 |
| 最佳实践 |
| 助手的唯一标识名。 |
| 助手的头像 Emoji。 |
| 选择符合其职业特征的 Emoji，如 🧑‍💻 代表程序员。 |
| 用于客户端分类展示，支持多选。 |
| 选择合适的标签（如：办公、代码、工具）。 |
| strong 核心配置 。定义助手的行为和责任。 |
| 使用结构化提示词（角色设定+任务目标+输出限制）。 |
| 助手的功能和用途的简要说明。 |
