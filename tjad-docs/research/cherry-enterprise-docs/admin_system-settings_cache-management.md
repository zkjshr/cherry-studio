# 缓存管理


## 状态指标说明
| 指标 |
| 含义 |
| 当前数据目录下的所有文件统计。 |
| 正在被知识库引用、或属于活跃对话记录的文件。 strong 系统会保护这些文件不被删除。 |

## 清理操作
- 点击 刷新统计 按钮，获取最新的磁盘扫描结果。
- 查看 无效文件 的数量和大小。
- 点击 清理无效文件 按钮执行清理。

## ⚠️ 风险警告
数据安全警告 ：
- 清理操作将 永久删除 无效
- 该操作不可逆。
- 虽然系统通过数据库比对来识别无效文件，但在执行清理前， 强烈建议 您备份 Cherry Studio 的数据目录，以防因软件逻辑边缘情况导致的重要附件丢失。
