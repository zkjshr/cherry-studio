# 添加自定义小程序


## 操作步骤
- 点击页面右上角的 + 添加小程序 按钮。
- 在弹出的对话框中完成以下配置：
| 参数模块 |
| 字段 |
| 说明 |
| 建议上传 strong PNG 或 strong WebP 格式，背景透明为佳。 br 推荐尺寸： code 200x200px ，最大不超过 code 200KB 。 |
| 显示在图标下方的文字（建议不超过 4 个汉字以保持美观）。 |
| strong 必须包含协议头 （如 code https:// ）。 br 示例： code https://docs.cherry-ai.com https://docs.cherry-ai.com |
| 开启后，图标周围会增加一圈细微的描边，适用于 Logo 颜色与侧边栏底色相近的情况。 |
| 为 Logo 设置底色（支持 Hex 色值，如 code #FFFFFF ）。若 Logo 为透明 PNG，设置背景色可增加辨识度。 |
- 点击 添加小程序 确认保存。
关于 URL 的限制 请务必使用 https:// 开头的安全链接。由于客户端的安全策略，普通的 http:// 链接可能会被拦截或无法加载。
